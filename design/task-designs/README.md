# Task designs

One summary per task. The playable graphs are in `content/dialogues/`. All places, people and products are fictional.

## Task 1: Getting around (station, Sam) → O1, O5
- **Goal:** a return ticket to Seaview, then the platform and directions. **Twist:** the machine shows CARD NOT ACCEPTED.
- **Shape:** greet → ticket (build turn) → price / off-peak (repair-friendly) → payment → platform → directions check → close. 18 nodes.
- **Odd options target:** orders instead of requests ("Fix it", "Give me"), dismissing help, "Yes." as a reply to "Have a good trip!"
- **Errors target:** missing verbs, *want go*, *today evening*, question word order (*I can pay ...?*, *Which platform it leaves?*), *I am understand*.

## Task 2: Café (Priya) → O2, O5
- **Goal:** lunch for you and Ana (nut allergy). **Twist:** the curry is sold out; the pesto has pine nuts and the salad has walnuts.
- **Shape:** order → sold out → allergy + ingredients (speak turn) → safe alternative (build turn) → eat in / take away → drinks → total. 19 nodes.
- **Safety framing:** the odd option "It's fine. She can just eat around them" gets feedback that it is a safety problem as well as a language one.
- **Errors target:** adjective order (*soup tomato*, *sandwich of cheese*), *allergy of*, *She don't*, *will to have*, missing subjects.

## Task 3: Pharmacy (Mr Okafor) → O3, O5 (language only)
- **Goal:** describe a sore throat; answer the follow-up questions; understand the (fictional) lozenge instructions.
- **Safety:** a safety note on the task page, a narrator line, signage and the final line all say "language practice only, not medical advice; ask a pharmacist or doctor". The product and dosage are fictional.
- **Shape:** problem → how long (build turn: *since* vs *for*) → symptoms (*swallowing* gloss) → other medicine → recommendation → dosage check → when to see a doctor. 17 nodes.
- **Errors target:** *I have it since yesterday*, *for three hours* vs *every three hours*, *I not take*, *When I must go to doctor?*

## Task 4: Hostel (Leo) → O4, O5
- **Goal:** check in. **Twist:** the booking starts tomorrow and tonight's private rooms are full; negotiate a dorm bed at the dorm price.
- **Shape:** check in → (spell name) → not found → explain + evidence (build turn, two accepted orders) → date mix-up → offer → (alternatives) → deal → confirm. 14 nodes.
- **Odd options target:** sarcasm, blaming the system, "not my problem", insulting the offer, threatening a review.
- **Errors target:** *do a reservation*, *I book it before one week*, *There is other room?*, *prefer ... than*, *It's work for me*.
