# Learning objectives

CEFR-informed (A2 → B1). Descriptor wording and page numbers: design/cefr-alignment.md.

| ID | By the end, the learner can... | Measurable evidence in the game |
|---|---|---|
| O1 | buy the right train ticket and ask for and understand simple directions | Task 1 goal achieved; effective choices in the ticket and directions turns; listening L1-L2 correct |
| O2 | order food for themselves and a friend and explain a dietary need (nut allergy), asking for clarification when needed | Task 2 goal achieved with a nut-free order; the allergy is stated before choosing; L3-L4 correct |
| O3 | describe a common minor health problem to a pharmacist, answer follow-up questions and check basic instructions (language only, no medical advice) | Task 3 goal achieved; "how long" (build) and dosage-check turns; L5-L6 correct |
| O4 | explain a problem with a booking and negotiate a simple solution | Task 4 goal achieved via an agreed alternative; L7 correct |
| O5 | use repair strategies: ask someone to repeat, slow down or spell, and check understanding | Repair buttons used (counted per task); "So ..., is that right?" options chosen; L8 correct |

Secondary aim (not assessed): recognise when grammatical English is pragmatically odd (too blunt, blaming,
off-topic), through the "odd" option feedback and recasts.

Evidence is formative only. The game shows the learner their own results and keeps a local, downloadable
xAPI-shaped record. It gives no grades and claims no levels.
