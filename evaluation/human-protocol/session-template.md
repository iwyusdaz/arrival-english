*Template only. No sessions have been run.*

**Participant code:** P__ **Self-reported level:** A1 / A2 / A2+ / B1 **Device:** desktop / phone **Mode:** 3D / text **Audio:** on / off

## Script (35-45 min)
1. Consent (consent-template.md). Explain think-aloud: "Say what you're thinking; there are no wrong answers."
2. The participant completes the Start-page can-do (before).
3. Tasks 1-4. Note for each: time, mode used (choose / build / speak), repair buttons used, odd or error choices, any confusion.
4. Listening check. Note use of replay and the speech-rate setting.
5. Can-do (after). Short interview:
   - Which moment felt most like real life? Least?
   - Did the staff reactions help you understand your mistakes?
   - Did you feel nervous at any point? When?
   - Was anything hard to read or hear?
6. Thank the participant. Clear browser data (Menu → My progress → Clear my data).
